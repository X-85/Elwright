# 工作总结 · 离线 SOP

> 这是技能型能力 `work-summary` 的离线降级文档。配置了 LLM 时由 AI 自动生成；离线时按本文手动执行。

## 用途

把一段时间的工作记录（聊天、提交、笔记）整理成上级/自己能快速消费的工作总结。

## 结构模板（周报/月报通用）

```markdown
# <周期> 工作总结

## 一、目标回顾
本周期初计划是什么（原样列出，用于对照）。

## 二、完成事项
- <动词开头> + <做了什么> + <量化结果>（例：完成支付模块联调，覆盖 12 个接口，通过率 100%）

## 三、未完成与原因
- <事项>：<原因> + <新计划时间>（诚实列出，比藏起来更专业）

## 四、问题与对策
- 遇到的主要障碍、当时的处理、需要谁支援。

## 五、下周期计划
- 按优先级列 3-5 项，标出风险项。
```

## 使用方法（离线）

1. **收集素材**：翻本周的聊天记录、git 提交（`git log --since="1 week ago" --author=我`）、待办清单。
2. **归类**：把素材按上面五个板块分堆，不归类的丢弃。
3. **量化**：每条完成事项强制补数字（几个/多少/百分比），没有数字的写清状态（完成/进行中 x%）。
4. **对照**：与周期初的目标逐条对照，完成的移入「二」，没完成的移入「三」。
5. **删减**：总长控制在一屏内，上级只关心结论与风险。

## 写作规则

- 每条以动词开头：完成/修复/推进/输出/协调。
- 不写「配合某某工作」这类无主语无结果的句子。
- 风险主动暴露，附上自己的对策建议，而不是只抛问题。
