# 周报生成 · 离线 SOP

> 这是技能型能力 `weekly-report` 的离线降级文档。配置了 LLM（`ELWRIGHT_LLM_BASE_URL` 等环境变量）时由 AI 执行；离线时按本文手动执行。

## 用途

把本周做的事（流水账、commit 记录、会议要点等原始素材）整理成一份结构化周报。

## 手动步骤

1. **收集素材**：翻本周的 git log、待办清单、聊天记录里答应过的事，逐条列出来，不用整理格式。
2. **按四个桶分类**：
   - 本周完成（有结果的事，写结果不写过程）
   - 进行中（写了但没完的，注明卡在哪、预计何时完）
   - 下周计划（从进行中推导 + 已确定的新任务）
   - 风险与求助（需要别人决策或配合的事）
3. **每条压缩成一行**：动词开头 + 对象 + 结果/状态。例：`完成注册接口联调，三方回调覆盖率 100%`。
4. **删掉纯过程条目**：开会、对齐、review 别人的代码除非有决策产出，否则不进周报。
5. **通读一遍**：老板只读这一页，能否看懂你本周的价值。

## 输出模板

```markdown
## 周报（MM.DD - MM.DD）

### 本周完成
- …

### 进行中
- …（卡点：…，预计：…）

### 下周计划
- …

### 风险与求助
- …
```
