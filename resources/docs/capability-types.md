# 能力类型速览

Elwright 里的能力分三类，区别在于「怎么被执行」：

| 类型 | 执行方式 | 依赖 LLM？ | 离网可用 |
|---|---|---|---|
| 脚本型 script | 本机解释器跑脚本（.py/.ps1/.sh 等） | 否 | ✅ 只要装了对应解释器 |
| 知识型 knowledge | 直接阅读 Markdown 文档 | 否 | ✅ |
| 技能型 skill | LLM 按提示词模板执行；LLM 不可达时降级为 SOP 文档手动执行 | 是（可降级） | ✅ 降级后仍可用 |

## 怎么选类型

- **规则固定、输入输出明确** → 脚本型。同样的输入永远得到同样的输出，不需要理解语义。
- **沉淀的是知识本身**（笔记、踩坑、方案对比）→ 知识型。价值在内容，不在执行。
- **需要理解、归纳、改写自然语言** → 技能型。有网走 LLM，没网看 SOP 照着手动做。

## 一句话记住设计哲学

LLM 是增强不是地基：核心功能离网可跑，技能型在 LLM 不可达时降级为 SOP 文档而非报错。
