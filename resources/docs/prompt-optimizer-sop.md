# 提示词优化 · 离线 SOP

> 这是技能型能力 `prompt-optimizer` 的离线降级文档。配置了 LLM（`ELWRIGHT_LLM_BASE_URL` 等环境变量）时由 AI 自动优化；离线时按本文手动执行。

## 用途

把一句简短粗糙的想法（如"帮我写个周报"）扩写成结构完整、可直接使用的提示词，提升 AI 输出质量。

## 六要素模板

逐项填写，缺哪项补哪项：

| 要素 | 回答的问题 | 示例（周报场景） |
|---|---|---|
| 1. 角色 | 你要 AI 扮演谁？ | 你是一位资深项目经理 |
| 2. 任务 | 要它做什么（动词开头） | 把我提供的流水账整理成结构化周报 |
| 3. 上下文 | 它需要知道的背景 | 团队 5 人，本周迭代 v2.3，读者是部门总监 |
| 4. 约束 | 限制与偏好 | 中文，不超过 300 字，突出问题与风险 |
| 5. 输出格式 | 结果长什么样 | 按「进展/风险/下周计划」三段 |
| 6. 示例 | 给一个参考样例 | 附上一份上周的周报作为范例 |

## 使用方法（离线）

1. 写下原始的简短想法（就是你现在脑子里那句话）。
2. 逐项过六要素表格，每项写出一句话；写不出来说明需求还没想清，先补想。
3. 把六要素串成一段自然语言提示词，交给你手头的任何 AI 工具使用。
4. 对比优化前后两次输出的差距，把有效要素沉淀成自己的常用模板。

## 质量自查

- 删掉任何要素后输出会明显变差吗？（不会 → 该要素是废话，可精简）
- 换一个 AI 收到这段提示词，能产出差不多质量的结果吗？（不能 → 关键约束没写够）
