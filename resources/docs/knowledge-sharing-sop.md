# 知识总结分享 · 离线 SOP

> 这是技能型能力 `knowledge-sharing` 的离线降级文档。配置了 LLM 时由 AI 把会话内容自动转成分享文档；离线时按本文手动执行。

## 用途

把一段有价值的 AI 对话（或自己的排查过程）提炼成别人能看懂、能复用的分享文档——而不是直接甩一整屏聊天记录。

## 分享文档结构模板

```markdown
# <一句话主题：解决什么问题>

## 背景
为什么遇到这个问题（1-3 句）。

## 结论
先说答案/方案是什么（读者最想要的，放最前面）。

## 过程要点
- 关键步骤 / 命令 / 配置（可复制粘贴的原文）
- 每步为什么这么做（一句话）

## 踩坑
哪一步容易走错、报错信息是什么、怎么绕开的。

## 适用范围
什么环境/版本验证过，什么情况不适用。
```

## 使用方法（离线）

1. **筛选**：通读会话，标出真正解决问题的 3-5 个片段，其余（反复试错、闲聊）丢弃。
2. **提炼**：把每个片段改写为「做了什么 + 为什么」，删掉对读者的废话。
3. **脱敏**：检查并删除内网地址、密钥、密码、公司内部系统名、真实姓名。
4. **结构化**：套上面的模板重排，结论必须前置。
5. **标题**：用「<场景> + <动作> + <结果>」起名，如「macOS 下 Rust 编译报 linker 错误的解决」。

## 质量自查

- 一个没参与这次对话的同事，只看文档能否复现？
- 结论是否放在第一屏（不用往下滚就能看到答案）？
- 敏感信息清零了吗？
