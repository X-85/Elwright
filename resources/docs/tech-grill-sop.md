# 八层拷问 · 离线 SOP（技术掌握度深挖）

> 这是技能型能力 `tech-grill` 的离线降级文档。配置了 LLM（`ELWRIGHT_LLM_BASE_URL` 等环境变量）时由 AI 执行；离线时按本文手动执行。

## 用途

对一个技术主题做八层递进式提问，检验自己（或他人）的掌握深度，暴露"以为懂了其实没懂"的层级。

## 八层提问模板

1. **是什么**：用一句话说清这个概念/技术是什么，不许用比喻。
2. **解决什么**：它解决什么问题？没有它之前人们怎么做、痛点在哪？
3. **怎么工作**：核心机制是什么？关键组件/流程如何协作？
4. **边界在哪**：适用场景和不适用场景分别是什么？为什么？
5. **怎么失败**：典型故障模式有哪些？失败时系统的表现是什么？
6. **如何权衡**：它做了哪些取舍？替代方案为什么在这些维度更差（或更好）？
7. **怎么验证**：如何证明你说的是对的？用什么实验、监控或数据能证伪？
8. **怎么演化**：它未来可能怎么变？如果重写一次，哪里会不一样？

## 使用方法（离线）

1. 写下要拷问的主题（如"Raft 共识"、"Rust 所有权"）。
2. 逐层回答，每层答案必须落在纸面，不许只在脑内过。
3. 任何一层卡壳超过 5 分钟，标记为知识空洞，回去补。
4. 第 7 层答不出 = 该主题停留在"听说过"；第 3 层答不出 = 从未掌握。

## 评分参考

- 8 层全过：可对外分享 / 可做技术选型。
- 过 1–4 层：会用，需补原理。
- 过 0–2 层：重新入门。
