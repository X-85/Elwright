## 7. FAQ

### Windows 上下载与安装 Elwright

> 背景：本机（公司 Win11）**不装 MSVC**，桌面 msi 由 GitHub CI 出。所以 Windows 上拿到桌面 app 只有一条路：**从 GitHub Release 下 CI 打好的 msi**。本地只负责用 GNU 编 `ew` + 浏览器 `npm run dev` 预览 UI。

**下载最新 msi（公司机，走代理 IWA 通道）**

公司网关封锁普通出网，但 `github.com` 可达，且 `curl --proxy-negotiate -u :`（当前登录用户的 Windows 集成认证）能过代理。PowerShell 一行：

```powershell
$proxy="http://10.182.0.99:9090"; $rel=(curl.exe -s --proxy-negotiate -u : -x $proxy https://api.github.com/repos/X-85/Elwright/releases/latest|ConvertFrom-Json); $msi=$rel.assets|Where-Object{$_.name-like"*x64*.msi"}|Select-Object -First 1; $out="D:\"+$msi.name; Write-Host "Downloading $($msi.name) (tag $($rel.tag_name))"; curl.exe -L --proxy-negotiate -u : -x $proxy -o $out $msi.browser_download_url; Write-Host "Saved -> $out"
```

这条命令会自动取**最新 release** 的 x64 msi 存到 `D:\`（如 `D:\Elwright_0.1.5_x64_en-US.msi`）。

**直接下载固定版本（当前 v0.1.5）**

不想跑 API 解析，直接贴链接（公司机仍需代理，浏览器可能也要走代理才能下）：

```
https://github.com/X-85/Elwright/releases/download/v0.1.5/Elwright_0.1.5_x64_en-US.msi
```

**安装**

MSI 右键菜单**没有**「以管理员身份运行」，需要提权时用：

```powershell
msiexec /i "D:\Elwright_0.1.5_x64_en-US.msi"
```

普通安装双击 msi 也行（装到当前用户，无需 admin）。

**注意事项**

- **回家/公网环境**：上面的命令把 `--proxy-negotiate -u : -x $proxy` 三段全去掉就是普通下载。
- 资源名规律：`Elwright_<版本>_x64_en-US.msi`（Windows）/ `Elwright_<版本>_aarch64.dmg`（macOS），用 `*x64*.msi` 过滤不会误抓 dmg。
- 公司网关**类别封锁**了 VS 下载 CDN（`download.visualstudio.microsoft.com`，403），所以本机装不了 MSVC、也无法本地 `tauri build`；msi 只能靠 CI。详见 ROADMAP「开发预览环境约束」。
- 装完验证：开始菜单找 `Elwright`（桌面 app）。**注意：msi 不含 `ew` CLI**——`ew` 是独立 bin 目标，release 工作流只 `tauri build`、没把它打进包。要用 CLI 必须单独从源码编译（见下方「本机日常开发命令」）。装完桌面 app 后运行 `Elwright.exe` 验证即可。

**本机日常开发命令（不装 MSVC 也能干）**

```powershell
# CLI / 核心改动（GNU 工具链，已验证可编）
cd Elwright\src-tauri
cargo +stable-x86_64-pc-windows-gnu build --bin ew

# 前端 UI 改动（浏览器预览，仅查看类功能可用）
cd Elwright\src
npm run dev
```
