# Elwright 工具路线图

> 工具类功能的明细排期。总路线图 [`docs/ROADMAP.md`](ROADMAP.md) 只保留阶段、优先级和状态；本文件记录工具范围、形态与验收边界。

## 约定

- **内置工具**：纯本地优先，默认不依赖网络、LLM 或第三方服务；适合高频、短时任务。
- **能力型工具**：需要复杂依赖、文件批处理或可扩展参数时，继续走能力注册表和用户叠加层，不把所有工具硬编码进工作台。
- **编辑型工具**：涉及文件写入时必须显式保存、显示目标路径，并保留路径边界与错误提示；预览模式不得伪装成真实持久化。
- 每个工具进入实现前，在 `docs/work/active/` 建独立任务目录，并补齐 Feature 文档或更新现有 Feature 文档。

## V2 计划

### P1：Markdown 文档预览与编辑

目标：把本地 Markdown 文件作为可管理资源，支持在 Elwright 内完成“打开 → 阅读 → 修改 → 明确保存”的闭环。

首期范围：

- 选择并打开工作区允许范围内的 `.md` 文件，左侧文档列表/最近文档。
- 编辑区与预览区切换，支持可信本地 Markdown 的标题、列表、链接、代码块、表格等常用语法。
- 明确的未保存、保存中、已保存、保存失败状态；保存前显示目标路径。
- 路径边界、敏感文件和超大文件保护；浏览器预览只读或使用虚拟文件，不写入用户真实文件。
- 可从资源管理器、课题工作区和代码浏览器打开 Markdown 文档；后续再评估文档内链接跳转、版本快照和全文搜索。

验收重点：真实桌面壳可读写指定 Markdown 文件；失败不丢原文件；预览与编辑内容一致；浏览器预览不会触碰本地文件。

### P1：JSON 转义与反转义

目标：补齐与日志、接口请求、配置文件和代码字符串相关的高频 JSON 小工具。

首期范围：

- JSON 字符串转义：引号、反斜杠、换行、制表符和控制字符按 JSON 规则处理。
- JSON 字符串反转义：仅接受合法 JSON 字符串或明确约定的字符串片段，错误显示中文原因。
- 与现有“格式化/压缩”共用输入、输出、复制和错误展示；纯前端本地计算。
- 不把“任意 JavaScript 字符串求值”纳入范围，避免引入执行代码风险。

验收重点：中英文、反斜杠、引号、换行、Unicode 和控制字符 round-trip；非法输入不静默改写。

## P2 候选

- 文本差异对比（纯本地、双栏、行级差异）。
- UUID / 正则测试 / URL 编解码。
- JSONPath 查询与 JSON Schema 校验（依赖和体积评估后再决定内置或能力化）。
- Markdown 文档目录、锚点和资源引用检查。

## 不内置工作台

- XLSX、DOCX、PDF 等复杂格式转换：优先作为能力注册表工具，由用户按需导入。
- 需要联网、上传内容或运行任意脚本的转换器：不作为默认内置工具。
