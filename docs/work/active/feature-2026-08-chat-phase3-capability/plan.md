# AI 对话阶段③计划：用户确认式能力协作

## 目标

对话中 AI 可提议能力调用、用户可主动选择能力；所有执行必须经用户确认，
复用现有 run/view/invoke 路径，结果可回灌对话上下文。

## 方案

- 系统提示动态注入能力清单（id/type/name）+ 严格提议格式约定
  （单独一行【能力提议】id: <id>；空注册表不注入）——`chat_system_prompt`
  可测 helper，chat_completion 接线。
- 消息标记协议（lib/chatProposal.ts）：提议/调用消息渲染为确认卡片
  （名称/类型/预期影响/参数输入），执行结果消息渲染为结果块 +
  「把结果告诉 AI」回灌按钮（截断 2000 字符保护上下文）。
- 执行分发：script→runScript（参数空格分隔）、knowledge→viewDoc、
  skill→invokeSkill（未配置模型走离线 SOP，结果标注来源）。
- 用户主动路径：输入区「⚡ 能力」选择器插入调用卡片。

## 非目标（阶段④）

- 流式输出、请求级取消、长上下文、跨平台完善。
- 自动执行（永远需要用户确认）、自动把结果回灌请求（用户点按钮）。
