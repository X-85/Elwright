# 代码浏览器阶段③（第一批）计划：研发上下文联动

## 目标

把代码浏览器从查看器升级为工作上下文入口：收藏文件、代码书签、
把用户明确选择的代码发送到 AI 对话。

## 范围（第一批）

- 收藏文件：目录树/文档栏星标切换，按项目根持久化（code-browser.json）。
- 代码书签：点击行号切换书签（备注默认取该行前 40 字符），书签面板点击跳回。
- 发送到 AI：文档栏按钮 → 确认面板（路径/范围/字符数，可取消）→
  选中片段优先、否则整文件（8000 字符截断）→ 切到对话页预填输入框，
  发送前用户可再编辑（沿用 AI 上下文规则：只有用户主动确认才进入请求）。

## 第二批（2026-08-31，本任务目录续）

- 转为 Todo：文档栏一键把当前文件（含代码位置标记 `绝对路径:行号`）创建为工作台 Todo；
  工作台 Todo 文本中的位置标记可点击，跳回代码浏览器对应文件与行。
- 终端定位：文档栏一键在集成终端新 tab 打开文件所在目录
  （TerminalPanel openTab 扩展 cwd 参数 + openAtDir）。
- 流程图关联不做（依赖工程图 MVP，后置验证项）。

## 数据

复用 `~/.elwright/code-browser.json`：RecentStore 扩 favorites（上限 100）
与 bookmarks（上限 200，项目根+路径+行号去重），新增两条切换 IPC。
