# 设置中心后续阶段计划

## 目标

把设置中心从"主题 + 模型"扩展为完整的本地偏好中心（常规/外观/终端），
保持本地优先与少而明确的准入标准。

## 本批范围

- 常规：启动视图（记住上次 / 固定视图）、启动时自动检查更新；语言项预留（i18n 基建未立项，置灰）。
- 外观：界面密度（舒适/紧凑，根 class 调整关键留白）、界面缩放（90/100/110/125%，root zoom）。
- 终端：字体（4 预设）、字号（即时生效）、滚动历史（对新输出生效）；
  xterm 主题保持与三态主题实时联动（原有能力）。

## 非目标（后续批次）

- 模型档案（多套 LLM 配置切换，涉及配置链改造，单独排期）。
- 界面语言 i18n（需先立 i18n 基建）。
- 无障碍偏好。

## 存储

全部 localStorage（`elwright.preferences`），与主题同源思路；逐字段类型校验
（mergePreferences），损坏数据回退默认值。
