# 代码浏览器第一阶段计划

## 目标

提供面向 Java 后端研发的本地项目只读查看入口，让用户可以快速浏览项目结构、定位代码，并为后续 AI 和工作流联动建立明确的代码上下文边界。

## 范围

- 代码浏览器入口和基础工作区布局。
- 用户主动选择本地项目目录。
- 项目目录树与文本文件打开。
- Java、配置文件、脚本、Markdown 的语法高亮或语言识别。
- 文件名搜索和当前项目内容搜索。
- 复制代码、复制文件路径、最近项目和最近文件。
- 第一阶段只读及敏感文件提示。

## 非目标

- 不实现完整 IDE、编译、调试和 Git 客户端。
- 不实现远程 SSH 文件浏览。
- 不默认扫描磁盘或上传代码。
- 不实现代码编辑、AI 自动修改或自动提交。

## 实施顺序

1. 扩展 `Bridge` 的项目选择、目录树、文件读取和项目搜索接口。
2. 建立 `CodeBrowserView` 及项目树、标签页、代码查看组件。
3. 加入路径边界、文件类型、大小和敏感文件限制。
4. 实现最近项目和最近文件的本地持久化。
5. 补充浏览器预览适配器和手动验证。

## 风险

- 文件读取越界会造成隐私和安全问题，必须由桌面端校验项目根和相对路径。
- 大型 Java 项目可能导致目录树和内容搜索阻塞，需要限制加载范围并分批读取。
- 引入代码编辑器依赖可能明显增大包体，第一阶段优先评估轻量方案。
