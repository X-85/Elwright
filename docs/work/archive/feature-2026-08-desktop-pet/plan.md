# 桌宠规划任务

## 目标

为 Elwright 规划一个低打扰、可关闭、离线友好的桌面工作入口，让用户从桌面快速搜索和调用已有能力，并获得清晰的任务状态与结果反馈。该功能当前属于独立实验方向，不进入主干近期排期。

## 任务类型

feature：新增桌面壳能力，涉及窗口/托盘、前端交互、Bridge、配置和跨平台验证。

## 实验验证范围

- 先验证桌宠是否能降低常用能力调用成本：托盘、显示/隐藏、快捷能力入口和任务状态反馈。
- 文档：Feature README/behavior/architecture/changelog、ADR、本任务 checklist/verification。
- 本任务不实现代码、不替换正式图标、不实现屏幕读取或自动操作电脑。

## 暂不进入主干的扩展

- Todo 摘要、番茄钟和复杂提醒。
- 自然语言能力匹配、场景组合和多桌面增强。
- 任何游戏化、养成或自动化 Agent 行为。

## 实施阶段

1. 先完成配置与桌宠窗口/托盘生命周期。
2. 增加桌宠专用 Bridge 与任务状态事件，复用现有核心执行路径。
3. 实现快速入口、搜索、收藏/最近使用和三类能力操作。
4. 实现结果反馈、失败/离线降级、敏感动作确认。
5. 完成设置、开机启动、位置恢复、macOS/Windows 验证后再进入发布。

## 风险

- 透明置顶窗口和托盘行为在 macOS/Windows 存在平台差异。
- 常驻进程、动画和提醒可能造成打扰或资源消耗，默认必须克制。
- 后台任务取消、重复执行和应用退出时的会话回收需要明确状态模型。
- 能力参数和结果可能包含敏感信息，历史记录默认最小化保存。

## 验证方式

- 前端构建、Rust 测试和桌面 debug 构建。
- macOS/Windows 真机验证显示/隐藏、拖动、托盘恢复、开机启动、退出回收。
- 离线环境验证脚本/知识可用、技能降级可见、桌宠本身可启动。
- 手工验证无确认不执行高影响任务、不会默认读取屏幕/输入/剪贴板。
