# Codex 式三栏应用壳

## 目标

将应用壳调整为简洁的左 / 中 / 右三栏结构，移除横跨页面的独立顶部工具栏。左栏顶部承载品牌、一级视图入口和能力工具操作；右栏顶部承载面板、终端和设置入口；中间只呈现当前业务内容。

## 范围

- 保留能力工具箱、AI 对话、消息会话、终端和设置的现有业务行为。
- 左右栏继续支持显隐；栏收起后提供边缘恢复入口。
- 收敛边界、间距和控件样式，避免重复标题和额外工具栏分割线。
- 更新应用壳 Feature 文档，记录新的区域职责。

## 非目标

- 不实现右侧上下文面板的具体业务内容。
- 不改变 Bridge、Tauri IPC、终端会话或能力数据协议。
- 不创建新的 Figma 文件或组件库；当前会话未提供可操作的 Figma 文件连接。

## 风险与验证

- 风险：聊天页自身含会话栏，需确保外层导航和内层会话栏仍可区分。
- 验证：前端构建、单元测试、`git diff --check`，并检查浏览器预览下三栏及窄屏收缩行为。
