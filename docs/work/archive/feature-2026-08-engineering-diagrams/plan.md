# 工程图规划

## 目标

在工作工具栏中增加面向 Java Web 和 Linux 研发工作的工程图工具，支持流程图、时序图以及 Mermaid 源码双模式，并连接脑图、AI、Todo、终端和日志分析场景。

## 主干 MVP

1. 流程图可视化编辑：节点、连线、属性、布局、预览和 Mermaid 导出。
2. 与 Todo、能力的关联，以及部署/故障排查模板。

## 后置/实验阶段

3. 时序图、Mermaid 源码双向模式和复杂源码保护。
4. AI/研发联动：文字/日志生成草稿、脑图转图、节点转 Todo、终端/服务器关联；需先证明对主干用户有通用价值。

## 非目标

- 不要求所有用户直接写 Mermaid。
- 不做通用白板、多人协作、复杂流程图编辑器或强制 PlantUML 运行时。
- 不自动读取终端、屏幕、剪贴板或执行 Mermaid/日志中的命令。
- AI 不直接覆盖原图、执行命令或上传未选择的日志。

## 验证方向

- 拖拉编辑与 Mermaid 生成结果一致；源码错误有位置提示且不丢失原文。
- 流程图和时序图可保存、重启恢复、导出 SVG/PNG/JSON/Mermaid。
- AI 草稿可差异预览、确认或取消，取消不改变原图。
- 日志发送范围、脱敏结果和关联对象清晰可见。
- macOS/Windows 画布、快捷键、文件路径和渲染验证。
