# 应用壳布局第一阶段计划

## 目标

调整 Elwright 桌面壳的空间组织：增加顶部全局操作栏，支持左右面板隐藏，并让终端默认完全隐藏、通过顶部入口按需展开。

## 范围

- 顶部品牌、AI 对话、能力工具箱、左右栏开关、终端入口和设置入口。
- 左侧现有导航内容迁移到可隐藏的左栏。
- 中间现有能力工具箱和 AI 对话保持原有行为。
- 增加可隐藏的右侧上下文面板占位。
- 终端抽屉收起时不占空间；“在终端中运行”继续自动展开终端。

## 非目标

- 不增加 AI 对话能力、工作工具栏、Todo、书签、脑图或工程图功能。
- 不实现右侧面板业务内容。
- 不修改 PTY、Tauri IPC、bridge、xterm 或 Rust 核心协议。

## 实施步骤

1. 建立应用壳 Feature 文档并将任务加入路线图。
2. 调整 `App.vue` 的壳层结构和区域显隐状态。
3. 调整 `TerminalPanel.vue` 的收起状态和公开控制方法。
4. 更新壳布局 CSS，验证窄窗口行为。
5. 更新集成终端 Feature 文档并完成构建验证。

## 风险与验证

- 风险：终端收起时卸载 xterm 可能影响现有会话，因此保留终端 DOM，仅将高度和可见性收为零。
- 验证：`npm run build`、`cargo test`，并手动检查桌面模式终端展开/收起与能力联动。
