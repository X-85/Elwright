# 工作工具栏规划

## 目标

为 Elwright 增加一个面向每日工作的统一工具栏，承载 Todo、书签、工作记录和常用开发转换工具，并与 AI 对话、能力工具箱和桌宠形成入口协作。

## 主干阶段

1. 工具栏基础框架：导航、分类、搜索、收藏、最近使用和用户层数据模型。
2. 每日工作工具：优先 Todo、书签。
3. 实用转换工具：优先进制转换、JSON 格式化、Java Bean ↔ JSON 中能直接服务研发闭环的部分。

## 后置/实验阶段

4. AI 联动：推荐工具、生成 Todo/书签、草拟转换参数，全部需要确认。
5. 今日记录、更多通用转换工具和桌宠快捷入口，先在独立实验分支验证，不默认进入主干。

## 非目标

- 不把所有工具强行注册为 script/knowledge/skill。
- 不默认读取剪贴板、屏幕或系统活动。
- 不让模型直接写入 Todo、书签、文件或执行命令。
- 不要求网络或 LLM 才能使用本地转换工具。

## 验证方向

- 工作数据只写用户层，内置资源和注册表不被修改。
- 转换工具在离线环境可用，错误输入有明确中文提示。
- AI/桌宠操作经过统一确认接口。
- macOS/Windows 验证本地路径、URL、窗口和托盘入口。
