# 资源管理与课题工作区

## 目标

- 提供本地优先的收藏夹资源树，支持文件夹最多三层。
- 提供课题工作区，可聚合文档、网页链接、能力和备注。
- 支持基于课题资源生成深度报告；LLM 不可用时返回可编辑的离线报告草稿。

## 范围

- 用户层 JSON 持久化，位于 `~/.elwright/workspace.json`。
- Tauri IPC 与浏览器预览 Bridge。
- Vue 工作区：资源树、课题列表、资源详情和报告生成。

## 非目标

- 不抓取网页正文，不上传本地文件。
- 不修改能力注册表协议，不把收藏夹写回 `capabilities.json`。
- 不实现多人协作、云同步或自动 Agent。

## 实现步骤

1. 定义 workspace 数据模型与 CRUD，增加 Rust 单元测试。
2. 增加 Tauri 命令和前端 Bridge；预览模式使用 localStorage。
3. 增加资源/课题视图及报告生成交互。
4. 更新 Feature 文档、路线图和验证记录。

## 验证

- `cargo test`
- `npm run build`
- 手动验证：创建三层文件夹、添加 URL/能力、创建课题、生成离线草稿。
