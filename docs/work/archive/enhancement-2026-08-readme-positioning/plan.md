# README 产品定位优化

## 目标

调整 README 开头的产品叙事，让首次阅读者先理解 Elwright 的使命和实际用途，再了解能力类型与技术理念。

## 范围

- 用“让更多人用上 AI，改变工作方式，把时间还给自己”作为开篇主张。
- 说明 Elwright 是 AI 增强型个人工作流工具，以及它如何帮助用户沉淀经验、减少重复工作、提高效率。
- 保留“LLM 是增强，不是地基”作为产品原则，说明无 LLM 时的可用性。
- 保留 Elwright 源自超人意象，并融合 AI 与实用工具的命名灵感。
- 让 README 的当前状态、内置示例和用户能力导入方式与路线图及实际版本一致。
- 收敛重复的 LLM 配置说明，把首次使用路径聚焦到安装、运行示例和按需扩展。

## 非目标

- 不改变安装、能力类型、CLI、桌面端或当前状态说明。
- 不修改产品功能和代码行为。

## 验证方式

- 通读 README 开头，确认使命、产品定位和使用价值顺序清晰。
- 检查 Markdown 格式和 Git diff。
