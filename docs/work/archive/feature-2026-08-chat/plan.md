# AI 对话页面规划

## 目标

在桌面应用中增加多轮 AI 对话页面，并逐步连接 Elwright 的能力体系，让已配置的大模型真正成为日常工作入口。

## 范围

- 对话基础、多轮消息、Markdown/代码块、发送/停止/重试。
- 本地会话管理与隐私保护。
- 用户确认式能力协作。
- 流式输出、取消和跨平台验证。

本任务当前只完成规划和路线图登记，不实现代码。

## 非目标

- 自动读取屏幕或剪贴板。
- 模型无确认执行脚本、写文件或控制终端。
- 云端同步、RAG、复杂 Agent 循环和多模型对比。

## 验证方向

- LLM 未配置、不可达、超时和非标准响应均有清晰状态。
- API Key 不进入前端消息、会话文件和日志。
- 会话删除、请求停止和应用退出能回收资源。
- 能力调用必须经过确认且复用现有执行路径。
