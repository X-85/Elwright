# 代码浏览器（Code Browser）

> 状态：**已规划，尚未实现**。这是面向研发工作的本地代码上下文入口，不是 IntelliJ IDEA 或 VS Code 的替代品。

代码浏览器帮助用户在 Elwright 中查看 Java Web 项目、定位代码和理解工作上下文，并把用户主动选择的代码片段交给 AI、Todo、流程图或能力工具继续处理。

## 产品定位

代码浏览器服务于以下工作闭环：

```text
选择本地项目 → 查看和定位代码 → 选择工作上下文 → AI 辅助理解 → 记录或执行结果
```

它首先是只读的“代码上下文入口”，而不是另一个完整 IDE。代码查看本身不依赖 LLM；AI 只处理用户明确选择的文件或代码片段。

## 分阶段路线

1. **本地项目只读查看**：选择项目、目录树、Java/配置文件预览、文件名和内容搜索、复制路径与代码。
2. **轻量代码跳转**：基于项目内符号和关系扫描，支持接口到实现类、JavaBean 类型到类定义、类名和方法定义跳转；不常驻启动大型语言服务。
3. **研发上下文联动**：最近项目、收藏文件、代码书签、Todo、发送到 AI、关联流程图和终端定位。
4. **受控修改与高级语义导航**：用户明确进入编辑模式，AI 生成补丁或差异；在确有需要时再评估 Java Language Server，不自动提交或推送。

## 明确边界

- 不默认扫描用户所有目录，只访问用户主动选择的项目。
- 不默认读取代码发送给 AI，敏感文件需要隐藏或警告。
- 第一阶段只读，不修改项目文件。
- 不建设完整 Git 客户端、远程 SSH 文件浏览或通用 IDE 功能。
