# 行为（Behavior）

## 第一阶段：本地项目只读查看

- 用户通过明确操作选择一个本地项目目录；应用不自行扫描磁盘寻找项目。
- 用户可以查看目录树，打开 Java、配置文件、脚本和 Markdown 等文本文件。
- 文件内容以只读方式展示，包含行号、语法高亮、折叠和基础滚动定位。
- 支持按文件名搜索，并支持在当前项目内搜索文本。
- 支持轻量代码跳转：点击接口或类型名称时，定位到项目内匹配的实现类或类定义；存在多个实现时先展示候选列表。
- 跳转优先使用已打开文件和轻量项目符号索引，不启动常驻高内存语言服务；无法可靠判断时退化为搜索结果，不伪造精确跳转。
- 用户可以复制代码片段和文件路径。
- 收藏文件与代码书签持久化在用户配置层（code-browser.json）；点击行号切换书签，收藏与书签面板可跳回。
- 发送到 AI 需经确认面板（展示路径、范围与字符数）；选中片段优先、否则整文件（超长截断）；内容填入对话输入框，发送前可编辑。敏感文件拒绝发送。
- 保存最近打开项目和最近查看文件，数据写入用户配置层；项目源文件不被修改。
- 浏览器预览模式提供明确的只读能力限制，不伪造桌面文件访问能力。

## AI 上下文规则

- 只有用户主动选择文件或代码片段并点击发送到 AI，内容才可以进入 AI 请求。
- 发送前展示文件路径、选中范围和内容摘要，用户可以取消。
- 不自动读取 `.env`、私钥、证书、凭据等高敏感文件；即使用户主动选择，也应显示风险提示。
- AI 返回的是解释、摘要或建议，不会在第一阶段直接写回文件。

## 阶段④：受控补丁编辑（受控写入）

- 用户在 AI 对话窗口收到一段 `\`\`\`diff` 围栏的补丁内容时，可点击「预览并应用到代码」打开三栏预览对话框（当前 / diff / 新）。
- 对话框只对最近打开过的项目生效；预览阶段不写文件，必须二次确认后才落盘。
- 支持单文件 / 多文件 diff；逐 hunk 列示，单文件可独立勾选「拒绝」（整文件拒绝时该文件所有 hunk 不写入）。
- 落盘后生成快照（`~/.elwright/code-browser/applied-patches.json`），按快照 id 支持一键回滚（回滚到本次写入前的内容快照）。
- 路径校验黑名单：`.env` / `.pem` / `.key` / `.ssh` / `.aws` / `node_modules` / `target` / `.git` 一律进 warnings 拒绝写入（即便用户已确认）。
- 没有走 VCS 的工作树由用户在终端自行 `git diff` 检查；Elwright 不自动 commit，也不替代 IDE 的编辑器模式。

## 非目标

- 不提供默认可编辑的代码工作区。
- 不实现自动项目分析、常驻后台全量索引、完整语义跳转、编译、调试或 Git 提交。
- 不实现远程服务器目录浏览；远程操作继续由终端能力负责。
- 不实现 Monaco 编辑器模式、自动保存、自动 commit、三路合并、语法校验或 LSP 全量语义。
- 不实现跨项目 / 跨工作区的批量补丁；每个 patch 只能影响单个最近项目的文件。
