# 行为（Behavior）

## 第一阶段

- 顶部新增“消息会话”入口，与 AI 对话并列；进入后显示会话列表和当前消息。
- 用户可通过应用内的新建会话面板填写对方名称或 Elwright 标识；第一阶段仅在本机创建会话，不依赖 WebView 对系统弹窗的支持。
- 支持发送文字、表情和本地图片；图片限制为 2 MB，并以内嵌缩略图保存到本地会话。
- 消息显示时间和本地状态；当前消息状态为“本地保存”，不会显示虚假的“已送达”。
- 会话和消息保存在浏览器 `localStorage`，刷新后保留；桌面端第一阶段也使用本地 WebView 存储。
- 删除会话前需要确认；删除仅影响本机数据。
- 页面明确提示网络消息服务尚未接入；不能将本地消息误认为已发给对方。

## 第二阶段（传输层核心，2026-09）

> 决策与取舍见 [ADR-002](./decisions/ADR-002-messaging-transport.md)；帧协议见 [transport-protocol.md](./transport-protocol.md)。

- 本地身份：首次使用消息传输功能时在 `~/.elwright/identity/` 自动生成密钥对
  （ed25519 签名 + X25519 协商），并派生 16 字符 base32 ID（Crockford，无 I/L/O/U）。
  密钥不出本机；删除该目录即重置身份。
- 邀请互加：一方生成邀请（6 字符短码 + 二维码原文，默认 5 分钟有效），
  对方粘贴二维码原文接受。校验含：格式 / 有效期 / ed25519 签名 / 短码一致性；
  任何一项失败即拒绝并给出中文错误。
- 中继配置：设置中心「消息中继」与 `ew config messaging {show,set,clear,test}`
  共用 `~/.elwright/config.json` 的 `messaging_relay_url` 字段。
  仅接受 `ws://` 或 `wss://`；「测试连接」实测一次 WebSocket 升级（5 秒超时）。
- 端到端加密：会话密钥经 Noise_XX_25519 协商，静态密钥即身份；
  数据帧为 ChaCha20-Poly1305 AEAD（重放自动拒绝，篡改即解密失败）。
  中继是纯密文转发器：只看房间 ID 与密文，日志零载荷（有自动化测试断言）。
- 离线队列：发送失败/对端不在线时，密文入 `~/.elwright/messaging/outbox.jsonl`
  暂存；明文永不落盘（单测强制）。
- **默认不启用**：未配置中继 URL 时消息功能保持第一阶段本地行为，不发起任何网络连接。

### 桌面端使用流程（2026-09-01 UI 接线完成）

- 设置中心「消息中继」：填自托管中继地址（`ws://`/`wss://`）→ 保存 →
  「测试连接」实测一次 WebSocket 升级（5 秒超时，中文结果）。
- 邀请互加：消息页 →「邀请」图标生成我的邀请（短码 + 原文，5 分钟有效，一键复制）
  → 对方「添加联系人」粘贴原文 → 双向校验（签名 / 有效期 / **ID 与 DH 公钥硬绑定**）
  后落盘联系人。
- 真实互发：绑定联系人的会话显示「端到端加密 · 经消息中继传输」；
  发送状态如实展示 `已送达 / 离线暂存·对端上线后补投 / 发送失败`，
  收到的消息 3 秒内自动并入会话（左侧气泡 + 「已接收」）。
- 降级不变：未配置中继 / 浏览器预览 / 后端不可用时，会话保持第一阶段纯本机行为，
  文案如实标注「本地保存」。
- 图片/表情仍仅保存本机（文字走端到端传输；图片协议在后续阶段评估）。

### 真机点验（遗留）

- 双账户经自建中继互发；篡改联系人 DH 公钥应握手失败（防中间人生效）；
  对端离线发送 → 上线自动补投；`docs/features/messaging/relay/` docker-compose 一键部署。
  官方不提供公共中继。

## 后续升级

- 接入服务后，保留现有会话和消息模型，新增送达、失败、重试、未读和在线状态。
- 消息会话可创建实时协作空间，保留聊天记录并关联流程图或代码。

## 非目标

- 不实现好友、群聊、朋友圈、账号体系或消息漫游。
- 不实现终端实时共享、隐式文件上传或自动执行对方发来的命令。
