# 行为（Behavior）

## 第一阶段

- 顶部新增“消息会话”入口，与 AI 对话并列；进入后显示会话列表和当前消息。
- 用户可通过应用内的新建会话面板填写对方名称或 Elwright 标识；第一阶段仅在本机创建会话，不依赖 WebView 对系统弹窗的支持。
- 支持发送文字、表情和本地图片；图片限制为 2 MB，并以内嵌缩略图保存到本地会话。
- 消息显示时间和本地状态；当前消息状态为“本地保存”，不会显示虚假的“已送达”。
- 会话和消息保存在浏览器 `localStorage`，刷新后保留；桌面端第一阶段也使用本地 WebView 存储。
- 删除会话前需要确认；删除仅影响本机数据。
- 页面明确提示网络消息服务尚未接入；不能将本地消息误认为已发给对方。

## 后续升级

- 接入服务后，保留现有会话和消息模型，新增送达、失败、重试、未读和在线状态。
- 消息会话可创建实时协作空间，保留聊天记录并关联流程图或代码。

## 非目标

- 不实现好友、群聊、朋友圈、账号体系或消息漫游。
- 不实现终端实时共享、隐式文件上传或自动执行对方发来的命令。
