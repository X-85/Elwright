# 桌宠（Desktop Pet）

## 定位

桌宠是 Elwright 桌面应用的轻量工作入口和陪伴层。它常驻桌面但不打扰用户，在需要时帮助用户快速找到能力、发起任务、查看进度和结果，让“把重复工作交给工具”变成更自然的日常动作。

它不是独立的 AI Agent，也不是自动操作电脑的助手。能力执行仍由 Elwright 现有 registry、executor、invoke 和 terminal 核心负责；LLM 仍是增强能力而不是运行地基。

## 当前状态

列为独立实验方向，尚未实现，也不属于主干近期排期。当前桌面应用已有能力列表、脚本执行、技能调用、离线 SOP、用户能力导入导出和集成终端，可作为实验的基础能力。

## 目标用户价值

- 不必打开完整主窗口，就能快速调用常用工作能力。
- 让任务状态、成功结果和需要用户处理的事项更容易被看见。
- 通过低打扰的提醒和轻量互动，帮助用户形成“沉淀能力、重复使用”的工作习惯。
- 离线时仍能使用脚本、知识和终端；技能型能力失败时展示 SOP，而不是让桌宠失效。

## 功能范围

### MVP：工作入口（第一版）

1. **常驻与召唤**：系统托盘运行；桌宠可显示/隐藏，支持拖动、靠边停靠、退出；主窗口关闭后桌宠是否继续运行可配置。
2. **快速入口**：展示最近使用、收藏和推荐的能力；点击后打开对应的任务面板或主窗口详情。
3. **快速搜索**：按名称、id、分类搜索能力；搜索结果区分脚本、知识、技能，并显示是否支持离线。
4. **任务发起**：脚本型能力填写参数后运行，技能型能力填写输入后调用；知识型能力打开文档。复用现有 Bridge，不在桌宠组件内直接访问文件或调用 Tauri API。
5. **结果与状态**：显示执行中、成功、失败、降级 SOP 等状态；结果可复制，必要时跳转主窗口查看完整输出。
6. **低打扰反馈**：仅在用户主动操作、任务完成或需要确认时展示气泡/状态；不默认弹出营销式提醒，不默认读取屏幕内容。
7. **基础设置**：开机启动、显示模式、主题/尺寸、透明度、提醒开关、快捷键、关闭桌宠；设置写入用户配置层。

### V1：工作陪伴

- 今日任务/最近任务摘要和一键重复执行。
- 轻量工作节奏提醒：可选番茄钟、休息提醒和自定义提醒，默认关闭或低频。
- 任务队列与历史记录：查看任务、重新执行、复制结果、清理记录。
- 能力快捷动作：收藏、固定到桌宠、从桌宠打开终端并带入命令。
- 状态表达：使用少量动画表达空闲、工作中、完成、等待确认和离线降级，不引入复杂角色养成系统。

### V2：可配置的个人工作伙伴

- 用户自定义快捷指令和场景组合。
- 基于本地任务历史的能力推荐，明确可关闭且默认不上传。
- 可选 LLM 对自然语言进行能力匹配和参数草拟，执行前始终展示目标能力、参数和影响范围。
- 多桌面/多显示器位置记忆和更完整的平台适配。

## 明确不做

- 不做自动点击、自动输入、后台替用户发送消息或修改文件的全自动 Agent。
- 不默认采集屏幕截图、键盘内容、麦克风、摄像头或窗口标题。
- 不把桌宠做成游戏、养成、社交或高频打扰组件。
- 不在桌宠中复制一套能力执行核心；CLI、主窗口、桌宠共用同一套核心与 Bridge 规则。
- 不要求联网或 LLM 才能启动和使用桌宠基础功能。

## 设计原则

- **先像工具，再像伙伴**：第一眼知道能做事，角色表达只服务于可理解的反馈。
- **主动召唤，低频反馈**：用户掌控出现、提醒和信息密度。
- **透明可确认**：涉及外部系统、文件写入或不可逆动作时，先显示具体动作并要求确认。
- **离线可退化**：脚本、知识、终端照常工作；技能型失败展示可执行 SOP。
- **可隐藏、可关闭、可恢复**：任何常驻和提醒都能被用户关闭，设置不应锁死用户。
