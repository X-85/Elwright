# 桌宠架构

## 边界

桌宠属于 Tauri + Vue 桌面壳能力，不进入 `src-tauri/src/core/`。共享核心只负责已有能力的注册、执行、LLM/降级和终端会话；桌宠负责窗口、托盘、交互状态和用户偏好。

```text
桌宠 Vue 组件
        ↓ Bridge / PetBridge
Tauri IPC：窗口、托盘、设置、任务事件
        ↓
现有 Bridge 操作 + 共享 core registry/executor/invoke/terminal
```

## 实现拆分

- **桌宠窗口**：独立无边框、透明、置顶窗口；可配置忽略鼠标、拖动和停靠。默认不抢焦点，点击搜索/输入时才进入交互态。
- **系统托盘**：显示/隐藏桌宠、打开主窗口、设置、退出；托盘作为不可见或桌宠关闭后的恢复入口。
- **PetBridge**：扩展现有 `Bridge`，封装桌宠所需的任务发起、取消/查询、偏好读写和事件订阅；组件不得直接 `fetch` 或调用 Tauri API。
- **任务模型**：第一版复用现有脚本/技能调用结果模型；需要后台队列、取消和历史时再引入桌面壳侧任务协调器。
- **偏好存储**：用户层配置文件增加桌宠配置段；写入采用字段级合并，不触碰内置注册表和资源。
- **平台适配**：优先 macOS 与 Windows；开机启动、窗口置顶、托盘菜单和多显示器行为使用 Tauri 插件或平台能力隔离。

## 安全边界

- 不给桌宠新增任意 shell 权限；脚本仍通过现有 executor 和能力注册表执行。
- 默认不提供后台自动执行和隐式重试；高影响任务必须有可见确认。
- 任务状态和错误通过事件推送，不能依赖轮询造成持续唤醒。
- 浏览器预览只展示不可执行的降级说明，不能伪装成桌宠运行态。

## MVP 技术顺序

1. 配置模型与桌宠窗口/托盘生命周期。
2. Bridge 任务接口和任务状态事件。
3. 快速搜索、收藏/最近使用和三类能力入口。
4. 结果面板、降级展示和确认流程。
5. 设置、开机启动、位置修正和跨平台打包验证。
