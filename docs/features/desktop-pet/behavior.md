# 桌宠业务行为

## 生命周期

- 首次安装默认不强制开机启动；用户可在设置中开启。
- 桌宠启动后默认处于空闲态，读取用户配置的尺寸、位置、透明度和提醒设置。
- 主窗口与桌宠可以独立显示；退出应用时终止桌宠及其未完成的本地任务会话，并给出明确状态。
- 位置超出当前显示区域时自动修正到可见区域，不覆盖系统关键区域作为硬性要求。

## 状态

`隐藏/未运行 → 空闲 → 搜索或等待输入 → 执行中 → 成功 | 失败 | 离线降级 | 等待确认`。

- 执行中允许打开任务详情，但重复点击不能创建意外的重复任务；是否允许并行由能力类型和后续任务模型决定。
- 成功状态展示简短结果和“查看完整结果/复制”；失败状态展示中文原因和重试入口。
- 技能未配置 LLM、网络失败或响应异常时进入“离线降级”，展示对应 SOP 路径和原因。
- 涉及文件写入、外部命令、外部网络或其他高影响动作时进入“等待确认”，确认前不得执行。

## 交互

- 单击桌宠打开快速入口；右键或菜单打开设置、主窗口和退出。
- 快速入口的搜索默认只匹配本地注册表与用户叠加层，不上传搜索词。
- 能力卡片显示名称、类型、离线标记和来源；执行前显示能力 id、参数和目标。
- 桌宠动画不承载业务信息，文字状态和颜色必须能独立说明结果。

## 数据与隐私

- 最近使用、收藏、位置和设置保存在本地用户配置；不得写入内置 `capabilities.json`。
- 任务历史默认只保存本地必要元数据；输出是否持久化由设置控制，默认不保存敏感输出。
- 桌宠不读取屏幕、剪贴板、输入法、麦克风或摄像头，除非未来新增功能明确开启并单独说明。
