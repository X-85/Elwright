# ADR-001：桌宠先做工作入口，不做自动化 Agent

## 状态

已接受（规划决策，待实现验证）

## 背景

Elwright 的使命是让更多人体验 AI 带来的工作效率变化，同时保持离网可用、透明和可控。桌宠如果直接承担屏幕理解和自动操作，权限、隐私和失败恢复会显著扩大，且会偏离现有能力模型。

## 决策

第一版桌宠只做常驻工作入口、能力搜索、任务发起、状态反馈、轻量提醒和设置。所有执行继续经现有能力注册表与共享核心；高影响动作在执行前需要用户确认。

## 后果

- MVP 范围可控，可以复用现有桌面壳和能力模型。
- 桌宠第一版的“智能”主要来自能力组织和低摩擦交互，而非全自动操作。
- 未来若引入自然语言匹配或自动化，必须单独设计权限、确认、审计和回滚机制。
