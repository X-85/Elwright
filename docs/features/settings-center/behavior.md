# 行为（Behavior）

## 第一阶段

- 点击顶部设置图标打开设置中心；关闭后回到原工作区，当前页面和终端会话不受影响。
- 设置中心包含常规、外观、模型设置三个分类，默认打开外观。
- 外观主题提供“跟随系统”“浅色”“深色”三个互斥选项。选择后立即应用到主界面，并保存到本地 WebView 存储。
- “跟随系统”监听操作系统颜色偏好变化，并在变化时同步界面。
- 模型设置复用原有字段、脱敏与测试连接行为；保存模型配置后刷新 AI 对话页的模型状态。
- 常规页在第一阶段仅作为设置结构入口，不引入未验证的通用偏好项。

## 数据边界

- 外观偏好为桌面应用的 UI 状态，保存键为 `elwright.theme-preference`；不写入能力注册表，也不修改 CLI/LLM 配置文件。
- 模型配置继续写入 `~/.elwright/config.json`，保持 CLI 与桌面端共用。

## 非目标

- 第一阶段不实现终端颜色同步、字号、语言、启动行为或更新策略的具体配置。
- 不增加云同步、账号体系或远程配置下发。
