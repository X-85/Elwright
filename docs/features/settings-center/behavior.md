# 行为（Behavior）

## 第一阶段

- 点击顶部设置图标打开设置中心；关闭后回到原工作区，当前页面和终端会话不受影响。
- 设置中心包含常规、外观、模型设置三个分类，默认打开外观。
- 外观主题提供“跟随系统”“浅色”“深色”三个互斥选项。选择后立即应用到主界面，并保存到本地 WebView 存储。
- “跟随系统”监听操作系统颜色偏好变化，并在变化时同步界面。
- 模型设置复用原有字段、脱敏与测试连接行为；保存模型配置后刷新 AI 对话页的模型状态。
- 常规页在第一阶段仅作为设置结构入口，不引入未验证的通用偏好项。

## 模型档案（Q19 多套 LLM 配置切换）

- 模型设置顶部新增「档案」下拉 + 「+ 新建档案」按钮；下拉中含一条"（flat 字段，未指定档案）" 哨兵与按字母排序的全部已配置档案，当前激活项前以 ★ 标记。
- 切换档案：先保存当前表单字段到用户层 flat，再调用后端切换激活；切换后刷新生效视图与档案列表。
- 新建档案：弹小窗输入名字（小写字母/数字/-/_，长度 1-32，前端校验 + 后端权威归一化）；以当前字段值为初值保存到 `profiles[name]`；保存后自动选中新档案并刷新。
- 删除档案：清单里逐档案「删除」按钮，激活档案删除时会弹确认"将自动回退 flat 字段"；后端同步清空 activeProfile。
- 旧 flat-only 配置（v0.1.10 之前）继续生效：list 返回空、getActive 返回 null、setActive 不存在的 name 报错——配置兼容性是底线。
- 浏览器预览模式：所有档案方法抛明确中文降级提示（与现有 set/getLlmConfig 一致），不模拟持久化。

## 数据边界

- 外观偏好为桌面应用的 UI 状态，保存键为 `elwright.theme-preference`；不写入能力注册表，也不修改 CLI/LLM 配置文件。
- 模型配置继续写入 `~/.elwright/config.json`，保持 CLI 与桌面端共用。

## 非目标

- 第一阶段不实现终端颜色同步、字号、语言、启动行为或更新策略的具体配置。
- 不增加云同步、账号体系或远程配置下发。
