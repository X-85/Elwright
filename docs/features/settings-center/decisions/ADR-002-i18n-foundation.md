# ADR-002：i18n 基建——轻量 t() + 双语字典，设置中心壳层试点

日期：2026-08-31 · 状态：已接受 · 来源：设置中心「界面语言」置灰的前置（ROADMAP）

## 决策

1. **自写轻量 i18n**（`lib/i18n.ts`，~50 行零依赖）：`locale` ref + 双语字典 +
   `t(key)`（缺 key 回退 zh-CN 再回退 key 本身）；不引 vue-i18n（当前需求简单，
   引依赖的收益不抵包体与约束）。
2. **preferences 新增 `language: 'zh-CN' | 'en'`**（默认 zh-CN，逐字段校验沿用既有
   模式）；`updatePreferences` 副作用同步 `setLocale`，切换即时生效并持久化。
3. **试点范围 = 设置中心壳层**（四个分区标题/说明/控件标签 + 语言选择器本体启用）；
   枚举选项标签（舒适/紧凑/启动视图选项/终端字体名）与 LlmSettings 内部文案为
   **增量迁移遗留**，键集完整性测试守护字典同步，其余视图按需增量迁移。
4. 字典按语言各一张平铺表，键名 `settings.*` 前缀；zh-CN 为源语言。

## 拒绝 / 后置

- vue-i18n / message-format 库：无复数/性别等高级格式需求，平铺字符串够用。
- 一次全应用迁移：字符串量大、回译质量难保证，按视图增量推进。
- 语言跟随系统：后续可加 `auto` 档，本期显式选择。
