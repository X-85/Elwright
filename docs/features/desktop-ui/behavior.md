# 桌面壳前端 —— 业务行为

## 列表与筛选

- 启动加载 `capabilities.json` 全部能力，展示名称、类型徽标（脚本/知识/技能）、id、分类、⚡离网标记。
- 类型筛选：全部 / 脚本型 / 知识型 / 技能型；搜索匹配 id / 名称 / 分类（不区分大小写）。
- 计数显示「当前筛选项 / 总项数」。加载失败显示错误信息。

## 详情（按类型）

- **script**：显示入口路径；参数输入（空格分隔）+「▶ 运行」。浏览器预览态：点击后提示无法执行并给出等价 CLI 命令（`ew run <id> …`）。
- **knowledge**：选中即加载并渲染 `doc`（回退 `entry`）指向的 Markdown；来源路径可见。文件不存在显示错误文案。
- **skill**：显示提示词模板与降级说明（含 `degradeDoc` 路径）；附加输入 +「⚡ 调用」。浏览器预览态：点击后固定展示降级 SOP（含「未接 LLM」横幅）——即降级 UI 的真实预览。

## 不允许的情况

- 预览模式下脚本不真实执行、技能不真实调 LLM（浏览器无法 spawn 进程 / 直连 LLM 端点）；均给出明确说明而非报错。
- `/api/file` 仅允许访问 `resources/` 前缀路径（防目录穿越）。

## 对外部系统的影响

- 浏览器预览：仅本机 dev 服务器只读 API，无副作用。
- Tauri 桌面壳（阶段 3b）：经 IPC 调用 Rust 核心，行为对齐 CLI（run 执行、invoke 调 LLM/降级）。
