# AI 对话业务行为

## 页面入口

- 桌面应用侧栏一级导航：「🧰 能力工具箱」⇄「💬 AI 对话」，可随时切换。
- 对话页头部显示当前 model（悬停可见各字段来源与 key 打码）；状态为：已配置 / 未配置模型 / 预览模式。
- 未配置模型时显示配置引导（一键打开 ⚙ 模型设置）和「离线能力不受影响」提示，不显示空白聊天或通用错误。
- 预览模式（浏览器）显示明确降级提示，不模拟对话。

## 消息与会话（阶段① 已实现）

- 支持 user / assistant 多轮消息；系统提示词由 Rust 侧固定前置（`CHAT_SYSTEM_PROMPT`），前端只传 user/assistant——试图注入 system 角色直接被 IPC 拒绝。
- 发送（Enter）/换行（Shift+Enter）；发送后显示「生成中…」脉冲状态，输入与切页全程可交互。
- **流式输出（阶段④）**：桌面端回复逐块呈现（50ms 节流渲染）；首字延迟为首个 SSE chunk。
- **停止（阶段④升级）**：停止按钮向后端发取消命令，真正中断读取（省 token、断连接）；已收到的部分文本保留并标注「（已停止）」。前端序号比对作为第二道防线保留。
- 失败（未配置/网络/协议错误）时显示中文错误气泡 + 「↻ 重试」；重试移除错误占位后按当前历史重发，原始用户输入保留。
- 模型输出按不可信 Markdown 渲染（ADR-002）：原始 HTML 转义为文本、链接仅放行 http(s)/mailto/锚点/相对路径；代码块带「复制」按钮。
- 超长输入（>20000 字符）仅显示提示，不拦截、不截断。

## 会话管理（阶段② 代码完成，待真机验证）

- 对话页左侧为会话侧栏：会话列表 + 「＋」新建；空列表显示「暂无会话」。
- **持久化**：每个会话一个文件 `~/.elwright/chats/<id>.json`（ChatSession：id/title/created_at/updated_at/messages）。消息变化（用户发出、回复成功、重命名）即自动保存；错误占位消息不入文件。
- 空会话不落盘：`＋` 新建的会话直到第一条消息成功持久化后才出现在列表中。
- **标题**：默认取第一条非错误用户消息（压缩空白、超 24 字符截断加 …），无则「新对话」；可重命名（✎ 或双击，Enter/失焦提交、Esc 取消）。
- **切换**：点击列表项加载该会话全部消息并滚到底部；列表按 updated_at 降序，最近会话排最前。
- **删除**：× 按钮弹确认；删除后自动选中列表第一项，无会话则开新会话。删除不存在的会话文件不报错（幂等）。
- 损坏的会话文件在列表与加载时被跳过，不影响其他会话。
- 预览模式（浏览器）：会话列表恒为空，保存/删除静默忽略，不模拟桌面持久化。

## 能力协作（阶段③ 已实现）

- 输入区「⚡ 能力」选择器列出全部能力，选中即插入确认卡片；系统提示动态注入
  能力清单与提议格式（单独一行【能力提议】id: <id>），模型回复中的提议同样渲染为卡片。
- 卡片展示能力名称、类型、预期影响和参数输入；模型只能草拟，确认按钮由用户点击。
- 确认后按类型分发：脚本→`run_script`（参数空格分隔）、知识→`view_doc`、
  技能→`invoke_skill`；结果为 assistant 消息【能力结果】，超 4000 字符截断。
- 技能未配置 LLM 时走离线 SOP 并在结果头标注来源；结果块带「把结果告诉 AI」，
  用户点击才把结果（截断 2000 字符）作为用户消息回灌并请求模型继续。
- 敏感规则不变：模型提议不自动执行；执行失败在卡片下方报错并可重试。

## 不允许的情况

- 不自动读取屏幕、剪贴板、键盘输入、麦克风或摄像头。
- 不因模型回复中出现代码、shell 命令或工具格式就自动执行。
- 不静默上传历史会话或在后台持续发送请求。
- 不把 API Key 或未脱敏的配置写进会话文件、日志或前端状态。
