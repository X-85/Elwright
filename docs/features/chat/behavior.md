# AI 对话业务行为

## 页面入口

- 桌面应用增加一级「AI 对话」入口，可返回能力工具箱。
- 页面显示当前模型、配置来源和连接状态；API Key 只显示打码信息。
- 未配置模型时显示配置引导和仍可使用的离线能力，不显示空白聊天或通用错误。

## 消息与会话

- 支持 user / assistant 多轮消息；系统提示词由应用控制，不允许用户通过普通输入覆盖安全规则。
- 发送后显示生成中状态；支持停止、失败重试和保留原始输入。
- Markdown 和代码块可阅读、复制；模型输出作为不可信文本展示，不执行其中的命令。
- 会话新建、切换、重命名、删除；默认只在本地保存，删除需作用于当前会话且不影响模型配置。

## 能力协作

- 用户可从对话页面主动选择一个能力，或请求模型推荐能力。
- 推荐结果必须展示能力名称、类型、参数和预期影响；模型只能草拟调用，不得直接执行。
- 用户确认后，脚本/知识/技能分别复用现有 `run`、`view`、`invoke` 路径。
- 技能型调用失败或未配置 LLM 时，展示已有离线 SOP；对话本身的请求失败保留会话并提供重试。

## 不允许的情况

- 不自动读取屏幕、剪贴板、键盘输入、麦克风或摄像头。
- 不因模型回复中出现代码、shell 命令或工具格式就自动执行。
- 不静默上传历史会话或在后台持续发送请求。
- 不把 API Key 或未脱敏的配置写进会话文件、日志或前端状态。
