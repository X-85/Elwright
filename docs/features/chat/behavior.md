# AI 对话业务行为

## 页面入口

- 桌面应用侧栏一级导航：「🧰 能力工具箱」⇄「💬 AI 对话」，可随时切换。
- 对话页头部显示当前 model（悬停可见各字段来源与 key 打码）；状态为：已配置 / 未配置模型 / 预览模式。
- 未配置模型时显示配置引导（一键打开 ⚙ 模型设置）和「离线能力不受影响」提示，不显示空白聊天或通用错误。
- 预览模式（浏览器）显示明确降级提示，不模拟对话。

## 消息与会话（阶段① 已实现）

- 支持 user / assistant 多轮消息；系统提示词由 Rust 侧固定前置（`CHAT_SYSTEM_PROMPT`），前端只传 user/assistant——试图注入 system 角色直接被 IPC 拒绝。
- 发送（Enter）/换行（Shift+Enter）；发送后显示「生成中…」脉冲状态，输入与切页全程可交互。
- **停止（阶段①口径）**：丢弃在途请求结果并立即恢复输入；后端 blocking 请求照常完成但结果不入列。请求级取消属阶段④。
- 失败（未配置/网络/协议错误）时显示中文错误气泡 + 「↻ 重试」；重试移除错误占位后按当前历史重发，原始用户输入保留。
- 模型输出按不可信 Markdown 渲染（ADR-002）：原始 HTML 转义为文本、链接仅放行 http(s)/mailto/锚点/相对路径；代码块带「复制」按钮。
- 会话仅内存态（切换视图保留、刷新即失）；本地会话管理（新建/切换/重命名/删除）属阶段②，未实现。
- 超长输入（>20000 字符）仅显示提示，不拦截、不截断。

## 能力协作

- 用户可从对话页面主动选择一个能力，或请求模型推荐能力。
- 推荐结果必须展示能力名称、类型、参数和预期影响；模型只能草拟调用，不得直接执行。
- 用户确认后，脚本/知识/技能分别复用现有 `run`、`view`、`invoke` 路径。
- 技能型调用失败或未配置 LLM 时，展示已有离线 SOP；对话本身的请求失败保留会话并提供重试。

## 不允许的情况

- 不自动读取屏幕、剪贴板、键盘输入、麦克风或摄像头。
- 不因模型回复中出现代码、shell 命令或工具格式就自动执行。
- 不静默上传历史会话或在后台持续发送请求。
- 不把 API Key 或未脱敏的配置写进会话文件、日志或前端状态。
