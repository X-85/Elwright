# ADR-001：工作台第二阶段——常用能力（收藏/最近使用）+ 高频研发转换工具

日期：2026-08-31 · 状态：已接受 · 来源：ROADMAP 工作台/资源工作区两条目的共同顺延项

## 范围

1. **常用能力**（承接能力调用）：新区块展示能力收藏（置顶）与最近使用（带时间），
   点击跳转能力工具箱并选中详情。收藏与最近使用存前端本机存储
   （`elwright-capability-favorites` / `elwright-capability-recents`，后者去重置顶、
   上限 8 条）；最近使用由 App 的能力 `select()` 时写入（与既有使用计数同时机）。
2. **实用工具**（少量高频、纯本地、零依赖，各带 vitest）：JSON 格式化/压缩
   （中文报错）、Base64 编解码（UTF-8 安全）、时间戳⇄日期（秒/毫秒自动识别）。
   输入输出双文本区 + 复制。

## 拒绝 / 后置

- 书签：代码浏览器已有行级书签体系，工作台不重复建；后续按需聚合展示。
- 更多转换工具（xlsx/docx 等）：走能力注册表（用户层导入），不内置进工作台。
- 常用能力直接在工作台内运行/调用：第一阶段先承接跳转，内嵌执行后续按需评估。
