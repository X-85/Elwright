# 工作工具栏业务行为

## 导航与工具分组

- 桌面应用增加一级「工作工具栏」入口，与 AI 对话、能力工具箱、集成终端并列。
- 工具栏内分为「每日工作」和「实用工具」；支持搜索、收藏和最近使用。
- 复杂工具使用独立页面或面板，不在桌宠中承载完整表单。

## 每日工作

### 已实现（第一阶段，2026-08-25）

- Todo 支持新增、勾选/取消勾选（划线样式与完成计数联动）、删除；创建序展示，无分组/标签/截止日（后续阶段）。
  - 空白内容拒绝（中文报错），单条上限 500 字符；未知 id 的 toggle/remove 报「不存在或已删除」。
- 今日记录：一天一文件（`notes/YYYY-MM-DD.md`），日期前后翻页查看/编辑；800ms 防抖自动保存（未保存/保存中/已保存/失败四态徽标）；Markdown 预览切换。
  - 日期参数后端严格校验（YYYY-MM-DD 形状 + 数值范围），防路径穿越；非法日期中文报错。
- 浏览器预览模式：工作台 UI 完整可用（进程内模拟存储，刷新即失），带明确【预览模式】提示；真实持久化只在桌面壳。
- 工作数据保存在本地用户层 `~/.elwright/`，不写入内置 `capabilities.json`。

### 规划中（后续阶段）

- Todo 编辑、优先级、截止日期、标签与筛选（原规划能力，未实现）。
- 书签支持 URL、本地文件/目录、终端目录、Elwright 能力和 AI 对话等目标；打开动作由用户主动触发。

## 实用转换

- 进制转换支持 2～36 进制，展示二进制、八进制、十进制和十六进制结果，并提供复制。
- Java Bean ↔ JSON 支持输入、格式化、转换、复制和保存；类名、包名、字段命名、Lombok/Jackson 等选项逐步增加。
- 输入格式错误显示具体位置和中文原因，不调用模型、不上传数据。

## AI 与桌宠联动

- AI 可推荐工具、草拟 Todo/书签和转换参数；写入或执行前必须用户确认。
- 桌宠可显示今日未完成 Todo 数量，并提供常用工具、书签和 AI 对话的快捷入口。
- AI 或桌宠不可绕过工具栏的确认、隐私和本地存储规则。
