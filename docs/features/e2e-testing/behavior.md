# 行为

- `npm run test:e2e` 启动独立 Vite 预览服务器并在 Chromium 中执行浏览器端到端测试。
- 每个测试开始时清空该测试浏览器上下文的 `localStorage`；收藏夹、课题和报告只使用浏览器预览 Bridge 的本地存储数据。
- 测试中的本地文件路径是虚拟 URI（`virtual://elwright-e2e/...`），不会读取、创建、移动或删除真实文件。
- 冒烟用例覆盖能力调用的离线 SOP、收藏夹创建与资源添加、课题创建与离线报告、设置中心开关，以及工作区无横向溢出。
- 系统文件选择器、启动本机软件、Tauri 窗口 API 和终端 PTY 仅在桌面壳可用，浏览器冒烟不将它们标为通过。
