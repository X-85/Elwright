# 工程图（Engineering Diagrams）

## 定位

工程图是 Elwright 面向研发工作的可视化表达工具，用来绘制流程图、时序图、系统架构图、状态图和 ER 图。它服务于 Java Web 开发、Linux 部署、日志排查和系统设计，与脑图的发散整理形成分工。

核心体验是“可视化编辑 + Mermaid 源码双模式”：普通用户通过节点、连线和表单编辑，研发用户可以直接修改 Mermaid；两者通过结构化图模型同步。

## 当前状态

已规划，尚未实现。主干 V2 仅验证流程图可视化编辑、Mermaid 生成/导出及其与 Todo、能力的关联；时序图和更深的 AI/终端/日志联动后置，需证明具备通用工作流价值后再排期。

## 分阶段范围

1. **流程图可视化编辑**：节点拖动、连线、节点属性、自动布局、Mermaid 生成、SVG/PNG 导出。
2. **时序图编辑**：参与者管理、消息时间线、同步/异步/返回、分组和条件（后置）。
3. **Mermaid 双向模式**：源码编辑、语法检查、支持子集的结构化模型回写和复杂源码保护（后置）。
4. **AI 与研发联动**：自然语言生成图、日志生成时序图、脑图转流程图、节点转 Todo、终端/服务器关联（后置，日志/终端数据必须用户选择并脱敏）。

## 设计原则

- 默认使用可视化编辑，不要求用户学习 Mermaid 语法。
- 结构化模型是可视化编辑的真相；Mermaid 是生成和高级编辑表示。
- 不支持完整结构化回写的 Mermaid 源码必须保留，不得静默丢失。
- AI 只生成草稿或差异，用户确认后才能写入工程图。
- 图形和日志默认本地保存；日志发送给 AI 前必须由用户明确选择，并提供脱敏能力。

## 首批图形

- 流程图：部署流程、故障排查、接口处理流程。
- 时序图：登录、下单、微服务调用链、异步消息和回调。
- 后续扩展：系统架构图、状态图、ER 图。
