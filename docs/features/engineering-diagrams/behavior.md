# 工程图业务行为

## 图形管理

- 用户可以新建、打开、重命名、删除和复制工程图，并选择图形类型。
- 工程图自动保存到用户层；删除前需要确认，保存失败时保留编辑状态并提示原因。
- 支持搜索、分类、收藏、最近使用和 JSON/Mermaid 文件导入导出。

## 可视化编辑

- 流程图支持添加开始、处理、判断、结束等节点，拖动布局，连接节点，编辑标签和条件。
- 时序图使用参与者列表和消息时间线编辑，支持请求、返回、异步消息、循环和条件分组；不强行用自由画布模拟消息顺序。
- 节点和消息可关联 Todo、书签、能力、终端会话或服务器，但关联对象失效时图形本身仍保留。

## Mermaid 源码

- 可视化模式生成 Mermaid 源码；源码模式支持编辑、复制、语法校验和预览。
- 支持的 Mermaid 子集可以回写结构化模型；复杂或未知语法仍可预览和导出，但切回可视化模式前必须提示可能无法编辑。
- 用户切换模式或导入源码时不得静默覆盖原始源码，需保留版本或提供明确确认。

## AI 与研发工作流

- AI 可根据文字、用户主动选择的日志或脑图生成工程图草稿。
- AI 修改以差异预览展示，用户确认后才写入；不会直接覆盖原图或执行命令。
- 工程图节点可转 Todo；节点关联终端、服务器和能力时，打开/执行仍须由用户主动触发。

## 隐私与安全

- 默认不读取终端全部输出、屏幕、剪贴板或本地项目。
- 用户选择日志发送给 AI 时，发送前显示内容范围并支持脱敏；工程图导出不包含原始日志和 API Key。
- Mermaid 代码块、日志和 AI 输出均作为文本处理，不自动执行其中的 shell、SQL 或 Java 代码。
