# 脑图（Mind Map）

## 定位

脑图是 Elwright 工作工具栏中的思考与规划工具，用来整理想法、拆解项目、沉淀知识，并把节点连接到 Todo、书签、AI 对话和 Elwright 能力。

它不是通用绘图软件，也不追求复杂的流程图和多人协作功能。第一版重点是结构化、可执行、可回到工作流中的个人脑图。

## 当前状态

已规划，尚未实现。脑图作为独立 Feature 维护，归入工作工具栏的“思考与规划”分组，并与 AI 对话、Todo、书签和桌宠联动。

## MVP 范围

- 新建、打开、重命名、删除脑图。
- 添加、编辑、删除、移动、缩进和调整层级。
- 展开/折叠、缩放、平移、自动保存。
- 节点颜色、标签、备注和完成状态。
- 节点转换为 Todo，关联书签、能力或 AI 对话。
- 撤销/重做、键盘快捷键。
- 导出 JSON、PNG/SVG；不依赖网络或 LLM。

## 后续阶段

1. 基础脑图编辑器和本地文件管理。
2. 节点与 Todo、书签、能力、AI 对话的关联。
3. AI 生成脑图草稿、拆解节点和总结脑图，确认后写入。
4. 桌宠打开最近脑图、显示待办摘要和快速新增节点。

## 明确不做

- 第一版不做多人协作、云端同步、实时共同编辑。
- 不做复杂流程图、甘特图、白板绘画和专业演示排版。
- 不自动读取本地项目、屏幕或剪贴板生成脑图。
- AI 不直接覆盖已有脑图；生成内容必须先预览差异并由用户确认。
