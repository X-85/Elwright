# 脑图业务行为

## 文件与编辑

- 用户可以新建脑图并设置标题；打开后显示根节点和子节点结构。
- 节点支持新增、编辑、删除、拖动排序、调整父子层级、展开和折叠。
- 编辑自动保存到用户层；删除脑图前需要确认，删除不影响关联的 Todo、书签和能力。
- 脑图支持撤销/重做；应用退出或保存失败时显示明确状态。

## 节点关联

- 节点可以关联 Todo、书签、Elwright 能力或 AI 对话，但关联对象删除后节点仍保留文本。
- 节点转换为 Todo 需要用户确认；Todo 完成状态可同步显示在节点上。
- 点击能力或书签关联时，先展示目标和打开/执行动作；执行仍由原有模块负责。

## AI 操作

- 用户可以请求 AI 根据输入生成脑图草稿、拆解当前节点、总结选中分支或发现缺失步骤。
- AI 结果以差异预览形式展示，不直接覆盖当前脑图。
- 用户确认后才写入新增或修改的节点；模型不可直接删除用户节点或执行关联能力。
- 未配置/不可达 LLM 时，脑图基础编辑、导入导出和节点关联继续可用。

## 导入导出

- JSON 是可恢复的结构化格式；PNG/SVG 是展示和分享格式。
- 导出不包含 API Key；关联对象保存稳定 id 和类型，无法解析时显示为失效关联。
