# 行为（Behavior）

## MVP（2026-09-01，ADR-001）

- 侧栏「脑图」入口；可建多张图（标题 ≤80 字符），一图一文件保存在本机
  `~/.elwright/mindmaps/`，改动防抖 400ms 自动保存（原子写）。
- 大纲树编辑：
  - 每行文本可直接编辑；Enter 在下方加兄弟节点并聚焦；
  - Tab 缩进（前一兄弟变为父节点）、Shift+Tab 外提；
  - Ctrl/⌘+↑↓ 与相邻兄弟整体交换（子树随行）；
  - 节点可折叠/展开（折叠时子树隐藏）；可删除（级联删子树）。
- 约束：根节点不可删/不可移动/不可缩进；一级节点不可外提（保证单根）。
- Todo 关联：节点行内「转 Todo」写入工作台并打 `todo` 标记（防重复转换）；
  工具栏「从 Todo 导入」把未完成 Todo 挂到选中节点（无选中挂根）。
- 降级：浏览器预览模式不读写本机文件，明确提示「【预览模式】脑图仅桌面端可用」。

## 非目标（ADR-001）

- 自由画布/放射状布局、AI 草稿生成子树、多人协作、云同步、通用白板。
