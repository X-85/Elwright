# 行为（Behavior）

## 第一阶段规则

- 应用打开后显示顶部全局操作栏、左侧导航和中间主工作区。
- 右侧上下文面板默认隐藏；本阶段只提供可显示/隐藏的壳占位，不提前实现具体业务内容。
- 点击“左栏”切换左侧导航的显示状态；点击“右栏”切换右侧上下文面板的显示状态。
- 中间主工作区不会被隐藏，左右栏收起后主工作区自动获得释放的空间。
- 桌面模式顶部显示“> 终端”入口。点击后从底部展开终端抽屉，再次点击收起。
- 终端收起时不保留可见标题栏，也不占用页面可用高度；已打开的会话和 tab 不因此销毁。
- 能力详情中的“在终端中运行”会新建终端 tab，并自动展开底部终端抽屉。
- 浏览器预览模式不显示真实终端入口，保留现有的运行/调用降级行为。
- 本阶段不改变能力列表、能力详情、AI 对话和终端 PTY/IPC 的业务协议。

## 响应式边界

窄窗口下左右侧栏自动隐藏，主工作区占满空间；顶部入口保持可用。终端仍按需从底部展开。

## 非目标

- 不实现右侧属性、参数、关联或结果的具体业务内容。
- 不实现终端分屏、SSH、命令历史持久化或远程会话。
- 不实现新的 AI 对话、Todo、书签、脑图或工程图页面。
