# 行为（Behavior）

## 当前规则

- 应用打开后显示左侧导航和中间主工作区；右侧上下文面板默认隐藏。
- 应用标题栏始终位于页面最上方，窗口控制组后显示 Elwright，左栏收起/展开按钮紧跟在品牌右侧；左栏内部不再重复放置该按钮。终端和设置位于左栏内部工具行，右栏只保留上下文开关。
- 桌面端关闭 Tauri 原生窗口装饰，使用紧凑的自定义标题栏；关闭、最小化、最大化按钮调用 Tauri 窗口 API，标题栏空白区域支持拖动窗口。浏览器预览保留同样的视觉按钮但为禁用态。
- 标题栏窗口按钮会阻止拖拽事件，避免点击按钮时被拖动行为拦截；窗口 API 失败时记录中文界面之外的控制台诊断信息。
- 桌面端必须在 capability 中授予 `core:window:allow-start-dragging`、`allow-close`、`allow-minimize` 和 `allow-toggle-maximize`，否则自定义标题栏只能显示而不能操作。
- 自定义标题栏的三色窗口按钮使用 14px 圆点、实色边缘和轻微悬停反馈，保证深色主题下不会显得发暗或被背景吞没。
- 布局面板的“全屏”入口在桌面端调用 `setFullscreen`；浏览器预览中的绿色按钮保持禁用。
- 应用标题栏与左侧导航使用同一 `--panel` 表面色，左侧区域不再出现标题栏和侧栏的色差。
- 标题栏底部不绘制横向分割线；左栏与主区之间的纵向边界复用工作区列宽，从窗口顶部连续到底部。左栏收起时该边界随列一起消失。
- 标题栏右侧空白区使用主工作区背景色，左侧品牌控制区使用左栏面板色，避免标题栏与下方对应区域出现错位色块。
- 标题栏左侧控制组包含窗口控制、品牌和左栏开关；右侧控制组按“终端、设置、右栏开关”排列并固定在标题栏最右侧。工作区内部不重复显示这些全局入口。
- 绿色窗口按钮在鼠标悬停时显示 Codex 式布局面板，鼠标移出按钮和面板后自动隐藏，点击页面空白处也会关闭；面板提供左/右/上/下半屏、填充屏幕、三列、四格、全屏和恢复窗口入口。桌面端按当前显示器工作区计算位置和尺寸，浏览器预览不执行真实窗口布局。
- 右侧上下文面板当前只提供壳占位，不提前实现具体业务内容。
- 点击左右栏顶部的面板按钮切换对应栏显隐；栏收起后，中间工作区边缘显示恢复入口。
- 中间主工作区不会被隐藏，左右栏收起后主工作区自动获得释放的空间。
- 桌面模式右栏顶部显示终端入口。点击后从底部展开终端抽屉，再次点击收起。
- 终端收起时不保留可见标题栏，也不占用页面可用高度；已打开的会话和 tab 不因此销毁。
- 能力详情中的“在终端中运行”会新建终端 tab，并自动展开底部终端抽屉。
- 浏览器预览模式保留左上角的禁用终端入口并提示“仅桌面模式可用”，不绕过现有的运行/调用降级行为。
- 本阶段不改变能力列表、能力详情、AI 对话和终端 PTY/IPC 的业务协议。

## 响应式边界

窄窗口下左右侧栏改为覆盖在主工作区之上，主工作区保持可用；边缘入口仍可恢复侧栏。终端仍按需从底部展开。

## 非目标

- 不实现右侧属性、参数、关联或结果的具体业务内容。
- 不实现终端分屏、SSH、命令历史持久化或远程会话。
- 不实现新的 AI 对话、Todo、书签、脑图或工程图页面。
