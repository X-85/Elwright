# 变更日志（Changelog）

## 2026-08-24 · Codex 式三栏壳层

- 移除横跨页面的独立顶部工具栏。
- 左栏顶部承载品牌、一级入口和能力工具操作；右栏顶部承载面板、终端和设置入口。
- 左右栏收起后提供边缘恢复入口，窄窗口改为覆盖式侧栏。

## 2026-08-24 · 顶部控制与终端入口调整

- 左栏左上角增加窗口控制视觉组，面板收起按钮与终端、设置入口保持同一控制行。
- 左右栏统一使用面板底色；浏览器预览保留禁用态终端入口。
- 后续调整：左栏收起/展开按钮提升到始终显示的应用标题栏，紧跟 Elwright 品牌，左栏内部不再重复显示。
- 桌面端改用紧凑自定义标题栏，避免 Tauri 原生装饰与应用标题栏叠加造成额外高度。
- 修复自定义标题栏操作无效：补充 Tauri 窗口拖动、关闭、最小化和最大化 ACL 权限。
- 放大并提亮标题栏三色窗口按钮，使其更接近 Codex/macOS traffic light 视觉。
- 绿色按钮改为真正的全屏切换，标题栏与左栏统一为 `--panel` 表面色。
- 移除标题栏底部横线，并将左侧纵向边界延伸到窗口顶部。
- 对齐标题栏分区表面色：右侧匹配工作区，左侧匹配左栏。
- 将右栏开关移到标题栏最右侧，将终端和设置移到标题栏左侧控制组。
- 将设置按钮从左侧控制组移到右栏开关左侧，形成右上角设置 / 面板组合。
- 将终端入口移动到标题栏右侧，并增加全屏、左右半屏和恢复窗口布局菜单。
- 将绿色按钮布局菜单改为悬停触发的 Codex 式图标面板，支持上/下半屏、填充、三列和四格排列；移出面板或点击空白处自动关闭。

## 2026-08-23 · 第一阶段规划与实现

- 新增顶部全局操作栏和三栏工作区的应用壳方案。
- 左右侧栏支持按需隐藏，中间主工作区始终保留。
- 终端从默认底部标题栏调整为顶部入口触发的按需展开抽屉。
