# 应用壳布局（App Shell）

> 状态：**第一阶段进行中**。本 Feature 描述 Elwright 桌面端的工作区布局与全局入口，不承载具体业务模块。

应用壳为能力工具箱、AI 对话和后续工作流工具提供统一的工作区。它采用顶部全局操作栏、可隐藏的左侧导航、始终保留的中间主工作区、可隐藏的右侧上下文面板，以及按需展开的底部终端抽屉。

## 设计目标

- 让主工作内容始终拥有稳定、连续的空间。
- 将低频或临时内容收起，减少视觉噪声。
- 终端作为执行和排查工具按需出现，不成为默认页面的底部空栏。
- 为后续能力详情、AI 对话和工作工具提供一致的入口位置。

## 区域职责

| 区域 | 职责 | 默认状态 |
| --- | --- | --- |
| 顶部操作栏 | 品牌、一级视图、左右栏开关、终端入口、设置 | 始终显示 |
| 左侧导航 | 当前视图的筛选、搜索和常用操作 | 显示 |
| 中间主工作区 | 能力列表、能力详情、AI 对话等当前任务 | 始终保留 |
| 右侧上下文面板 | 当前对象属性、参数、关联和结果 | 隐藏 |
| 底部终端抽屉 | 本地 shell、多 tab 和命令执行反馈 | 隐藏 |

## 代码位置

- `src/App.vue`：应用壳、区域显隐和顶部入口。
- `src/style.css`：壳布局和响应式规则。
- `src/components/TerminalPanel.vue`：终端会话与底部抽屉展开状态。
