# 会话问题台账

内置基准能力 `session-ledger` 提供一套长期会话的本地问题台账协议。它与本机 Codex Skill `$session-ledger` 共享相同的目录模型和记录规则。

Elwright 入口位于 `capabilities.json` 和 `resources/docs/session-ledger-sop.md`；Codex 安装入口位于 `~/.codex/skills/session-ledger/`。相关行为见 [behavior.md](./behavior.md)、技术边界见 [architecture.md](./architecture.md)。
