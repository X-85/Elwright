# 行为

- 注册表能力的 `releaseTier` 缺省为 `1`，核心能力默认显示并可使用。
- `releaseTier > 1` 的能力默认从列表隐藏；用户点击“查看全部能力”后可查看其元信息，但待解锁能力的执行按钮不可用。
- `unlockAfterUses` 可声明本地使用次数门槛；使用次数和“查看全部”偏好保存在前端本机存储，不上传服务端。
- **解锁规则透明（ADR-001）**：列表「待解锁」徽标悬停、详情页锁定横幅均显示具体条件与进度——「累计使用任意能力 N 次后自动解锁（当前 T/N）」；`unlockAfterUses` 缺失的进阶能力显示「暂未开放解锁条件」。
- **成长提示（ADR-001）**：累计使用跨过门槛的瞬间弹出「🎉 已解锁进阶能力「名称」」；侧栏持续显示距最近可解锁项的进度（「距解锁「Y」还差 N 次」）。
- 内置示例中 `weekly-report`（周报生成）为进阶档位（tier 2，累计使用 3 次解锁），作为成长闭环的开箱示例；其余为核心档位。
- 社区提交、远端代码执行和强制留存机制不属于本 MVP。
